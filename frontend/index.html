    How it works

    A Go worker requests each site every 10 seconds and times how long the first response takes. Each site keeps its own baseline from its last 100 good readings. A reading counts as a spike when it is more than 3 standard deviations above that baseline and at least 20 ms slower. Readings reach this page through Redis and a WebSocket.

    Made by harshmittal09. History lives in memory, so it starts fresh whenever the server restarts.
