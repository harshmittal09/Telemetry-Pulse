    How it works

    A Go worker requests each site every few seconds and times how long the first response takes. Each site keeps its own baseline from its last 100 good readings, and a reading that is far above that baseline is flagged as a spike. Readings reach this page through Redis and a WebSocket.

    Made by harshmittal09. History lives in memory, so it starts fresh whenever the server restarts.
